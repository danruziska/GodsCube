The `.asset` files next to each font are TextMesh Pro font atlases made from these fonts, and they are covered by the same license as the font they come from.

## Alagard and Romulus

Pixel fonts by Hewett Tsoi (the files themselves name the author as Pix3M). Both are listed as 100% free on DaFont. The author asks for credit when Alagard is used, and appreciates it for Romulus. This file and the project README give that credit.
